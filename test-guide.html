测试通关秘籍

v0.2.0 夜巡版 · 作者测试用 · 后半部分包含完整剧透

新故事与新难度已上线。看过攻略的功能测试，请勿混入盲测成功率。

先看：第一关怎么过

你截图里的“摔裂的手机”是剧情证据，不负责开门。开门道具是另一张桌子上的电视遥控器。

  1. 读完开局三段主线，最后点击“拿起外套，去找她”。如果还停在证据面板，先关闭面板。
  2. 环顾房间，找到老式电视。以出生时朝向407门的方向为准，电视在左侧、稍靠后的位置；不要继续检查右侧电话旁的手机。
  3. 走近电视柜上的黑色长条遥控器。看到“电视遥控器”名称后，点击名称，或面向遥控器按 E。
  4. 在“两节备用电池”面板中，点击“取出电池，装入门锁”。当前原型会自动完成安装，不用再打开背包使用物品。
  5. 左下角物品栏出现“备用电池”，左上角目标改为“门锁已恢复供电。走近407房门离开。”
  6. 回到贴有407门牌的房门，走近后点击“407 房门”名称，或面向门按 E。进入“四层回廊”，第一关完成。

如果只能看到“靠近查看”，再向前走一点；如果 E 没反应，先关闭阅读面板，再把画面中心对准目标。也可以直接点击已经可调查的名称。

第一关没有密码锁，不需要找完所有证据。住宿须知、手机、电话和镜子属于补充叙事与线索。遥控器取电池 → 自动安装 → 调查407门，是最短过关路线。

操作与新标记
  • WASD 移动；按住画面拖动环顾；方向键前进、后退、转身。
  • E 调查，也可以点击附近物件名称或物件本身。
  • J 查看证据、文字记录和自己的推理笔记；Esc 关闭阅读面板或暂停。
  • 场景名称标记用金黄色表示“物件”、青蓝色表示“记录”、浅绿色表示“通道”。这些分类不告诉你哪条信息是真的。
  • 纸张中的深红色加粗黑体与下划线标出可核对的信息。包括“独自退房”这类可能不可信的话，也会标出；高亮不等于正确答案。
  • 阅读时巡查倒计时暂停。提示不会降低通关概率。
第二关：四层回廊
  1. 往前走，调查左侧清洁车的“平面图”，了解服务梯藏在布草柜后面。
  2. 调查右侧柜上的“可设定的闹钟”。选择“上弦，然后观察巡查”。
  3. 右上角出现30秒巡查计时：前4秒“正在走向声源”，中间22秒“正在检查声源”，最后4秒“正在返回”。沿走廊找到尽头左侧布草柜。
  4. 只在“正在检查声源”阶段调查“布草柜后的服务梯”。过早或过晚冒险推柜子会退回本区入口。不要直接贴近值夜人。进入“306 医务间外”。

不要把走廊尽头的普通楼梯当成出口，它会让你回到原处。可以调查一次，收集“我写过这张纸”。直接硬推布草柜会触发惊吓和退回，证据不会丢失，也不计入最终失败率。

第三关：306 内线
  1. 调查右侧桌上的内线电话。
  2. 选择“现在约定一段新节奏，让她换个物件回应”。收集“一次笨拙的回应”：她会换工具、尝试、失误和重新回应。
  3. 记下本轮电话里显示的三个节奏，再调查左墙“暖气管回应”，按本轮顺序敲击。三个可能约定是“短长短 / 长短短 / 短短长”。不要固定照抄旧墙牌。 本轮约定保存在文字记录中，也可以再次接电话核对。
  4. 出现“收到了，是你”后，点击“去306，打开外侧门闩”。这一步只关闭面板，还需要实际走到306门前。
  5. 调查后方两扇门中标着“306”的右门，选择“从旁边进入值班室”。

左门“布草间”会重复童年磁带里的同一句话。可以调查获得对照证据，但不是前往下一关的门。错误敲击会累计警觉。同一区域第三次错误会引来值夜人，让你退回本区入口；证据和本轮约定保留。这不算一次最终破局失败。

第四关：夜间值班室
  1. 先调查复核台右侧“设备维修贴纸”，再调查右墙“医务柜”。前者证明同一次报时是录音机01:49 / 监控01:45，后者证明剪刀上的纱线与绷带一致。然后调查“监控校时台”。
  2. 将“监控时间补正”滑块调到 +4 分钟。
  3. 用“上移”排成：
  • 01:49 入口：林川带伤进门
  • 01:52 医务间：林遥拿起剪刀
  • 01:56 楼下：林川独自离开
  1. 初始顺序是“剪刀、入口、离开”，所以给“入口”点一次“上移”即可。
  2. 在“剪刀在这段记录中的用途”下拉框选择 “她剪开纱布，替我包扎”，点击“提交这次还原”。看完两段完整录像，最后点击“取出录音机下的侧门钥匙”。广播建议的“往回调四分钟”是错误的；应该补正+4。错误提交同样会累计警觉，第三次退回本区入口。
  3. 调查右前方标着“档案”的门，穿过侧门，进入“医务间与寄存室”。

维修贴纸、医务柜和原始录音可补充证据。核心发现：林川进门时已经受伤，妹妹拿剪刀是为了剪纱布包扎，广播剪接的解释不可靠。

第五关：广播档案室

进入后，先完成重逢的两段情节：把右手交给她 → 陪她取回行李。然后调查左侧寄存桌“包里的旧相机”，完成两段对话，收好相机。

之后可以读中央桌上的三份对照材料：

外套、重新包扎和相机属于必经主线。入口附近的电话是额外线索。电话中选择表达担心，会收集“相同的话，不同的回应”。

中央桌子有碰撞，要从桌子左侧或右侧绕过去。走到尽头消防门旁，调查墙上的“消防门钥匙”，选择“取下钥匙”。然后调查标着“一层”的门。离开本区前要完成重逢和相机情节。三份住客材料没有收集数量门槛，漏读会增加终局误判的可能。

第六关：一层出口——成功路线
  1. 看完一层的两段情节，理解哥哥害怕“不再被需要”。走到双扇正门前，调查其中一扇。终局可先选“先问她们现在发生的事”：正门旁的人会回应新伤口，楼梯口只重复争吵时的旧话。
  2. 对象选择：叫住正门旁披着外套的人。
  3. 方式选择：亲口对眼前的人说话。
  4. 下面两种表达都能成功：
  • “我爱你。我来这里，因为我想见你。你以后还可以来找我。”
  • “我舍不得你，也想让你过你自己的日子。你对我一直很重要。”
  1. 按住“按住，开口”按钮或空格，累计约6秒。中间松开只暂停，不清零；可以继续按住。
  2. 出现“我听见了”和“天亮以后 · 逃脱结局”。最终字幕是：失语者，唯开口诉爱才能破局。

正确解法没有随机失败，也没有“证据必须收集满多少份”的隐藏门槛。这里判断的是向真实对象亲口表达爱；不强制使用固定三个字。

组合条件同时错误时，按“独自离开 → 对象错误 → 使用录音 → 话语内容”的优先顺序确定失败原因。

选择“先停一下”或关闭选择面板，不会直接判定最终失败。探索中的惊吓和退回也不计为破局失败。

重试、存档和40%目标
  • 循环结局点击“带着证据，再试一次”，会回到一层。证据和之前的尝试记录保留，无需重打前五关。
  • 刷新页面后，点击“继续上次的夜晚”。选择“进入407 → 开始新游戏”会替换当前浏览器存档。
  • 本地地址与线上地址不共享存档，不同浏览器也不共享。此次更新兼容原有存档。
  • 结局页面可以导出试玩记录。第一轮失败、第二轮成功时，首轮指标仍然记录失败。
  • 看过这份秘籍的测试记录不能用于衡量新玩家40%首轮成功率。 这些记录只用于功能验证。
  • 40%成功 / 60%失败仍是待盲测校准的目标。本版没有通过随机数强行凑比例。
  • 首次探索按约15分钟设计，没有强制15分钟倒计时。熟悉答案后可以更快完成。
建议验收顺序
  1. 全程静音，从407到出口，确认所有信息都能通过文字获取。
  2. 查看手机证据，确认“林遥、我其实……、01:42、没有发送、干涸的血迹”与普通正文有明显字体区分。
  3. 靠近遥控器，确认名称可以点击；取电池后目标更新；重新读手机不会影响开门。
  4. 分别尝试错误节奏、错误校时，确认可重试且没有丢失证据。
  5. 选择录音进入循环，检查证据保留，再重试逃脱。
  6. 说话按住两秒后松开，再继续，确认进度不会清零。
  7. 导出记录，检查首轮结果、重试次数、证据和提示次数。
